This is my work on the Google Product Analytics Dataset

Link to my main story on Tableau: https://public.tableau.com/app/profile/sarthak.bansal2505/viz/Google_Product_Analytics_Tableau/MainStory

Tools Used: Python, SQL, BigQuery, Tableau
* Python was used to pull the data from Google Cloud's BigQuery and aggregate it to use in Tableau
* SQL was used via the Pandas library in Python as the query language
* Tableau was used to visualize and demonstrate insights about the aggregated data

Time Series KPIs: Active Users, Avg Order Value, Avg Revenue Per Session/User, Session / User Conversion Rate, Total Revenue and no. Transactions (by Day, Week, Month, and Overall)

Acquisition KPIs: Total Revenue / Transactions / Sessions / Users, Avg. Revenue by Session/User overall or by Source, Session / User Conv. Rate  (by Date, Medium, Source)

Funnel KPIs: Views / Carts / Purchases (overall)

Retention KPIs: Retention Rate (Starting Month, Month Diff)
